## 一、现状评估与竞品对标

### 1.1 能力基线总览

| 能力域 | 本项目现状 | 行业标杆 | 差距评级 |
|--------|-----------|---------|---------|
| **数据覆盖** | A/港/美三市场，日线为主，多源降级链 | 聚宽：Tick级+分钟线+A股1990年起；米筐：多市场+加密货币 | 🔴 较大 |
| **回测引擎** | Backtrader 日线级，6策略，A股佣金模型 | 聚宽：Tick级回测+参数寻优；VeighNa：Alpha 158因子+Cython加速 | 🟡 中等 |
| **因子体系** | 14个因子，YAML驱动，2个profile | 优矿：2000+因子库；BigQuant：300+AI因子；大智慧：数千特色因子 | 🔴 较大 |
| **筛选引擎** | 38个可组合条件，双层筛选，向量化引擎 | 同花顺iFinD：条件选股+智能选股；Choice：多维度筛选 | 🟢 领先/持平 |
| **ML闭环** | LightGBM+Purged CV，训练→推理→回测→筛选 | VeighNa 4.0：Alpha 158+101因子+多算法；BigQuant：AutoML | 🟡 中等 |
| **策略管理** | YAML DSL+策略打包/导入导出 | 聚宽：策略商城+社区分享；米筐：无代码编辑 | 🟡 中等 |
| **持仓/卖出** | L1+L2卖出引擎(12信号)，组合四维诊断 | 多数平台仅有止盈止损 | 🟢 领先 |
| **市场监控** | 六维情绪面板，美股盘前总结 | 东方财富：资金流向+龙虎榜；开盘啦：涨停板分析 | 🟡 中等 |
| **告警推送** | 5通道(Server酱/Bark/PushPlus/Webhook/控制台) | 聚宽：微信推送信号；大智慧：API+微信多渠道 | 🟢 持平 |
| **前端体验** | 单页SPA+6视图+ECharts | TradingView：业界最佳图表；米筐：视觉设计最舒服 | 🔴 较大 |
| **实盘交易** | 模拟盘PaperBroker+券商接口预留 | 聚宽：华泰/国君直连；Alpaca：API免佣金交易 | 🔴 较大 |
| **社区/生态** | 无 | 聚宽：12万+用户社区；BigQuant：策略商城+知识库 | 🔴 较大 |
| **部署方式** | CLI/API/调度器+Docker四容器 | 米筐：Docker本地部署；QuantConnect：云端 | 🟢 持平 |

### 1.2 核心优势（护城河）

1. **全链路闭环**：数据采集→因子分析→策略筛选→回测验证→ML预测→持仓管理→卖出决策→模拟交易，覆盖完整投资生命周期
2. **卖出引擎深度**：L1风控+L2信号加权(12信号)的卖出决策引擎，在个人级产品中罕见
3. **38条件可组合筛选**：双层筛选+向量化引擎，条件丰富度优于多数竞品
4. **多源降级架构**：akshare→Baostock→pywencai→pytdx→yfinance 五级降级，数据可用性强
5. **YAML驱动配置**：策略/因子/指标/调度全YAML化，可版本控制、可分享
6. **市场情绪六维模型**：投机/市场/板块情绪+三项综合评分，体系化程度高

### 1.3 核心短板

1. **数据频率不足**：仅有日线数据，缺少分钟线/Tick级数据
2. **因子库太小**：14个因子 vs 行业平均2000+
3. **前端体验粗糙**：单HTML文件，无组件化，图表交互弱
4. **无实盘交易**：模拟盘完善但无法对接券商实盘
5. **无社区生态**：缺少策略分享/跟单/因子市场
6. **回测深度不够**：无参数寻优、无Walk-Forward分析、无多周期组合回测
7. **无风险模型**：缺少Barra风格因子风险模型

| 参数敏感性 | 参数微扰下收益变化热力图 |

**技术方案**：
```python
# src/strategy/backtest/optimizer.py
from optuna import create_study

class ParamOptimizer:
    def __init__(self, strategy_cls, param_space: dict):
        self.strategy_cls = strategy_cls
        self.param_space = param_space  # {"fast_period": (5, 30), "slow_period": (20, 60)}
    
    def optimize(self, code, market, days, n_trials=100, method="bayesian"):
        study = create_study(direction="maximize")
        study.optimize(lambda trial: self._objective(trial, code, market, days), 
                      n_trials=n_trials)
        return study.best_params, study.best_value
```

**向量化回测引擎方案**：
```python
# src/strategy/backtest/vector_engine.py
import numba
import numpy as np

@numba.jit(nopython=True)
def vectorized_backtest(signals: np.ndarray, close: np.ndarray, 
                         commission: float, slippage: float):
    """向量化回测，比Backtrader快100x"""
    n = len(signals)
    positions = np.zeros(n)
    equity = np.zeros(n)
    equity[0] = 1.0
    
    for i in range(1, n):
        if signals[i] == 1 and positions[i-1] == 0:  # 买入
            positions[i] = equity[i-1] / (close[i] * (1 + commission + slippage))
            equity[i] = positions[i] * close[i]
        elif signals[i] == -1 and positions[i-1] > 0:  # 卖出
            equity[i] = positions[i-1] * close[i] * (1 - commission - slippage)
            positions[i] = 0
        else:
            equity[i] = positions[i-1] * close[i] if positions[i-1] > 0 else equity[i-1]
    
    return equity, positions
```

## 七、风险与应对

| 风险 | 概率 | 影响 | 应对策略 |
|------|------|------|---------|
| 数据源不稳定（akshare限流/接口变更） | 高 | 高 | 多源降级已实现+持续扩展备用源+数据本地化缓存 |
| 前端重构工作量大 | 高 | 中 | 分阶段迁移，旧HTML与Vue并行运行 |
| 实盘交易合规风险 | 中 | 高 | 仅对接合规券商通道+用户实名+风险提示+不提供投资建议 |
| 用户增长缓慢 | 中 | 中 | 开源引流+社区运营+免费版获客+内容营销 |
| LLM API成本 | 中 | 中 | 本地模型降级(ollama)+请求缓存+分级调用 |
| 竞品免费化冲击 | 低 | 中 | 差异化（本地部署+卖出引擎+LLM助手）不可替代 |

## 附录：技术选型参考

| 领域 | 技术选型 | 理由 |
|------|---------|------|
| 前端框架 | Vue 3 + Vite + TypeScript | 轻量、生态好、学习曲线低 |
| UI组件库 | TailwindCSS + Headless UI | 灵活、无样式锁定 |
| K线图表 | KLineCharts / TradingView Lightweight Charts | 专业金融图表、轻量 |
| 代码编辑器 | Monaco Editor | VS Code同内核、功能强大 |
| 后端框架 | FastAPI (现有) | 已使用、异步支持好 |
| 数据库 | SQLite (单机) / PostgreSQL (多用户) | 分级选择 |
| 缓存 | Redis | 热点数据+实时行情 |
| 消息队列 | Redis Stream | 轻量、够用 |
| 任务调度 | APScheduler (现有) / Celery (分布式) | 分级选择 |
| ML框架 | LightGBM (现有) + PyTorch (深度学习) | 渐进式扩展 |
| LLM | Claude API + Ollama (本地降级) | 云端+本地双路 |
| 部署 | Docker (现有) + K8s (集群) | 分级选择 |
| 监控 | Prometheus + Grafana | 开源标准 |
